# Lab 4: Introductory Javascript

Modify `index.html` so that:

## 4-1: Logging to Console

- clicking the "+1" button increaseses a counter and logs it to the console
- hitting shift+enter in the text box logs the contents to the console and clears the box

## 4-2: Modifying Attributes and Style

- clicking the "Recolor" button sets the word "Rainbow" to a random color

## 4-3: Modifying DOM Structure

- clicking the "Add" button adds a bingo square
- clicking the "x" icon in a bingo square deletes it
